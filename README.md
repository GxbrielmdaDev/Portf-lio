# Portfólio - Gabriel Almeida

Meu portfólio pessoal desenvolvido com React, Vite e Tailwind CSS.

## Funcionalidades

- Design responsivo e moderno com tema escuro
- Seções: Hero, Sobre, Tecnologias, Projetos, Lojas e Contato
- Animações suaves com Framer Motion
- Formulário de contato com envio via Webhook do Discord
- Projetos com imagens e modal de detalhes

## Tecnologias

- **React 19** — Biblioteca para construção de interfaces
- **Vite 8** — Bundler e dev server rápido
- **Tailwind CSS 4** — Estilização utilitária
- **Framer Motion** — Animações declarativas
- **React Icons** — Ícones (Feather, Simple Icons)

## Projetos em destaque

- **Boardly** — Sistema de organização de tarefas e anotações
- **ATLAS CONTROL** — Sistema de gestão de estoque
- **ABNTFlow** — Plataforma SaaS para formatação ABNT

## Scripts

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Inicia servidor de desenvolvimento |
| `npm run build` | Gera build de produção em `dist/` |
| `npm run preview` | Preview do build localmente |
| `npm run lint` | Verifica código com Oxlint |

## Estrutura

```
src/
├── assets/         # Imagens e recursos estáticos
├── components/     # Componentes React (Navbar, Hero, About, etc.)
├── data/           # Dados do portfólio (projetos, skills, etc.)
├── App.jsx         # Componente raiz
├── index.css       # Estilos globais e tema Tailwind
└── main.jsx        # Entry point
```
